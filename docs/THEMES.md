# Графические схемы GPT-Pi 5

Настройки → **Графическая схема** выбирают оформление всей панели и Ассистента.
Исходная **Fluent** сохраняет светлый и тёмный режимы. Ещё 12 схем переносят характер
меню Swypetris: у Solarized Light и GitHub Light светлый фон, у остальных — тёмный.
Для них режим задан самой схемой, чтобы сохранить исходную палитру.

Выбор оформления сохраняется только в браузере (`gpt-pi-scheme`, прежний
`gpt-pi-theme` для Fluent). Это предпочтение внешнего вида, не профиль человека
и не настройка облачного аккаунта. Если браузер запрещает сохранение, выбор
действует до закрытия страницы, о чём сообщает интерфейс.

## Характер тем

Названия `finish` в таблице — фактические токены Swypetris. Описания характера —
дизайнерская интерпретация изученных меню; ниже отдельно приведены идеи авторов.
Композиция GPT-Pi 5, Fluent-компоненты и единая типографика сохраняются.

| Схема / ID | Finish | Характер и приём переноса |
| --- | --- | --- |
| Classic / `classic` | `pixel` | Ранние цветные ПК: тёмно-синее поле, кремовые рамки, чёткие углы и пиксельный ритм. |
| Monokai / `monokai` | `syntax` | Энергия подсветки кода: угольная основа, лайм, розовый и голубой; небольшие квадратные отметки по краям. |
| Gruvbox / `gruvbox` | `warm` | Тёплая ретро-палитра: кремовый текст, охра, оливковый акцент и двойная рамка. |
| VSCode / `vscode` | `editor` | Сдержанная рабочая среда: нейтральный графит, мятный контур, ясная структура и минимум украшений. |
| Dracula / `dracula` | `gothic` | Ночная готика: чернильно-фиолетовая основа, ледяной голубой и небольшие угловые детали. |
| Nord / `nord` | `frost` | Северная тишина: сине-серые поверхности, холодная пастель, двойные контуры и лёгкие блики инея. |
| Solarized Light / `solarized_light` | `paper` | Тёплая бумага: кремовый фон, глубокий сине-зелёный текст и сдержанная бирюза. |
| Solarized Dark / `solarized_dark` | `petrol` | Глубокий петроль: сине-зелёная основа и светлый текст, сбалансированные цветовые акценты. |
| GitHub Light / `github_light` | `clean` | Чистая дневная рабочая среда: белое пространство, светло-серые карточки и синий акцент. |
| Tokyo Night / `tokyo_night` | `rain` | Дождливый ночной город: индиго, голубые линии, лиловые отражения и редкие штрихи дождя. |
| Catppuccin / `catppuccin` | `satin` | Мягкий сатин Mocha: тёмная сине-фиолетовая основа, округлые поверхности и спокойная пастель. |
| Synthwave '84 / `synthwave_84` | `arcade` | Аркада 1980-х: пурпур, электрический циан, двойная рамка и тонкие строки экрана. Сложные срезанные углы исходника упрощены до радиуса 8 px. |

Авторские идеи, проверенные при исследовании 2026-11-11: [Gruvbox](https://github.com/morhetz/gruvbox)
описывает различимые пастельные ретро-цвета и комфорт; [Nord](https://github.com/nordtheme/nord) —
16 приглушённых арктических оттенков и минимализм; [Solarized](https://github.com/altercation/solarized) —
16 цветов с контролируемой светлотой CIELAB и согласованные светлую/тёмную версии.
[Catppuccin](https://github.com/catppuccin/catppuccin) ставит во главу баланс контраста,
теплоту и гармонию. [SynthWave '84](https://github.com/robb0wen/synthwave-vscode)
вдохновлена музыкой synthwave, обложками и эстетикой 1980-х.
[Tokyo Night](https://github.com/folke/tokyonight.nvim) описывается автором как чистая
тёмная тема; образ дождя здесь взят из оформления Swypetris. Для остальных строк
таблицы не приписывается авторам вымышленный манифест.

## Границы переноса и источники

- Список стабильных ID и игровая палитра: [`GamePalette.kt:97–132`](https://github.com/RoyMatus/Swypetris/blob/bb2403f18e46d56e27321522e74c7fc8333eb8ed/app/src/main/java/ru/itoltec/swypetris/GamePalette.kt#L97-L132).
- Применение меню-токенов: [`MenuSkin.kt`](https://github.com/RoyMatus/Swypetris/blob/bb2403f18e46d56e27321522e74c7fc8333eb8ed/app/src/main/java/ru/itoltec/swypetris/MenuSkin.kt).
  Декор изучен по `app/src/main/res/drawable/menu_<id>_card.xml` и
  `menu_<id>_primary_normal.xml`, сцены — по `drawable-nodpi/menu_scene_<id>.png`.
- Атрибуция исходных адаптаций: [`theme-sources.txt`](https://github.com/RoyMatus/Swypetris/blob/bb2403f18e46d56e27321522e74c7fc8333eb8ed/app/src/main/assets/theme-sources.txt).
  Это адаптированные палитры, не полные реализации тем редакторов или их интерфейсов.
- В GPT-Pi цветовые роли сопоставлены собственным компонентам через
  [themes.mjs](../frontend/themes.mjs) и [appearance.jsx](../frontend/appearance.jsx).
  Hover/pressed-поверхности, разделители и позитивные индикаторы адаптированы для
  приложения; не каждый производный CSS-цвет дословно взят из Swypetris. Оттенки
  отрицательных значений и записи осветляются/затемняются до контраста 4.5:1
  на фоне, панели и выделенной поверхности; исходный JSON не меняется.
- Орнамент остаётся у краёв, текст читается на спокойных поверхностях. Игровые
  атласы фигур и московские сцены не переносятся в качестве фона под текст.
  Дополнительные шрифты не нужны. Изображение фотографии не перекрашивается темой.

## Рендеры и приёмка

`build/theme-renders/` предназначен для рендеров собранного интерфейса с синтетическими
источниками. Они показывают оформление, а не реальные погоду, рынки, показатели
компьютера, события или переписку. Проверки и ограничения фиксируются отдельно
по [TESTING.md](../TESTING.md). Наличие схем и рендеров не означает установки на Pi
или приёмки физического экрана.
