# OpenAI: факты, ограничения и решения

Проверка официальной документации: 2026-10-14. Повторить перед реализацией.

## Подтверждённые факты

- Sign in with ChatGPT предусматривает вход и отдельное разрешение на использование
  плана для допустимых запросов. Документация описывает open-source flow и
  ограниченный доступ для некоторых других клиентов. Это не выдача всех функций ChatGPT.
- Identity scopes сами по себе не дают доступа к беседам ChatGPT или API.
- В preview использования плана есть ограничения: в частности, отсутствуют
  аудиовход, transcription и ряд hosted tools, включая image generation.
- Realtime WebRTC имеет отдельный документированный путь с backend-аутентификацией
  API-ключом. Нельзя считать, что OAuth-токен плана поддерживает этот же путь.
- Облачные токены должны оставаться в защищённом локальном/backend-хранилище.

## Вывод для проекта

Вход через ChatGPT оставляем в требованиях и проектируем отдельным адаптером.
Для голоса исследуем API Realtime либо локальные STT/TTS с текстовой моделью.
Переход на API с оплатой по использованию должен быть явным выбором владельца.
Не делать скрытый fallback при исчерпании подписки.
Матрица capabilities зависит от подключения, модели и проверенных разрешений.

## Пока не установлено

- Можно ли выбранному приложению/аккаунту зарегистрироваться и использовать план.
- Допустима ли схема «несколько людей используют одну персональную подписку».
  Технические локальные профили не доказывают такое разрешение.
- Региональная доступность по месту эксплуатации и ограничения конкретного аккаунта.
- Точный набор моделей, квоты, стоимость и права на каждый инструмент.
- Подходит ли проект под OSS-flow: публичный репозиторий без OSS-лицензии
  сам по себе не подтверждает соответствие.
