These images guide implementation tickets; they are not screenshots of implemented features.
All telemetry, quotes, weather, calendar events and the slideshow photograph are synthetic examples.

Use Microsoft Fluent 2 / Fluent UI React v9. Target the actual 720 x 1280 portrait display.
Keep six tabs in this order: Обзор, Компьютер, Рынки, Календарь, Фото, Ассистент.
Photos fill the screen during playback; navigation and playback controls appear on touch.
Computer telemetry and the photo library originate on the user's computer, not implicitly on the Pi.
Existing authentication, model selection, cancellation, local voice and audio checks must remain accessible.
Follow the linked issue acceptance criteria when a generative image contains approximate geometry or illustrative values.
