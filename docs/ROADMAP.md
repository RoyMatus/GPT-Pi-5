# План разработки

## M0 — заготовка
- [x] Описание продукта, архитектура, инструкции для ИИ.
- [x] Offline UI и backend, доменная модель, автономные тесты и CI.
- [x] Шаблоны автозапуска и задание на корпус.

- [x] Проектные навыки, роли, выбор проверок и изолированные GitHub-инструменты.

## M1 — определить ограничения
- [ ] Подтвердить комплектующие, ОС/графическую сессию и интерфейсы подключения.
- [ ] Выбрать лицензию и проверить облачную доступность, бюджет, условия общего использования.
- [ ] Уточнить приватность: обычные пользователи, администратор, украденный накопитель.

## M2 — локальные профили
- [ ] Создание/вход/выход/блокировка, ограничение попыток, сессии и безопасное хранение.
- [ ] Постоянное изолированное хранилище бесед, памяти, файлов и экспортов.
- [ ] Негативные тесты IDOR и смены профиля во время потокового ответа.

## M3 — текст и облако
- [x] Личный прототип: connection и секреты только в памяти backend-сеанса.
- [x] Документированный OAuth/PKCE, ID-token validation, refresh и попытка revocation.
- [x] Текстовый чат, streaming, отмена, ошибки лимитов и capabilities; fake-cloud тесты.
- [ ] Завершённый вход реального аккаунта и реальный запрос в поддерживаемом регионе.
- [ ] Отдельно согласованная альтернатива API с оплатой/кредитами.

## M4 — голос и экран
- [ ] Проверить capture/playback на реальных устройствах, эхоподавление и задержку.
- [ ] Push-to-talk, прерывание, mute, индикация, очистка буферов при блокировке.
- [ ] Kiosk, экранная клавиатура, размеры кнопок и сценарии без сети.

Личный текстовый прототип v0.2 (2026-11-10) использует официальные компоненты
Fluent 2, установлен на Debian 13 ARM64 с Wayland и экраном 720×1280.
Сборка и браузерные проверки выполнены, служба и kiosk запущены. Это не закрывает
пункты про физический тач, звук, постоянные профили и приёмку голоса.

## M5 — функции и корпус
- [ ] Инструменты добавлять по одному с разрешениями и подтверждением действий.
- [ ] Замеры, CAD, тестовый макет, тепловые/акустические испытания, заказ печати.
- [ ] Автозапуск на Pi, тест отключения питания, backup/restore и rollback обновлений.

Готовность этапа означает выполненные критерии docs/PRODUCT.md, а не наличие заглушек.
