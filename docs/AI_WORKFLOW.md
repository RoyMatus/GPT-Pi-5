# Навыки, роли и инструменты разработки

Это настройка помощников разработчика. Она не реализует голос, OAuth или профили
пользователей в самом устройстве.

## Организация

AGENTS.md содержит общие ограничения; TESTING.md — выбор проверок.
В .agents/skills находятся 11 коротких навыков, в .codex/agents — четыре роли.
Роли наследуют модель и права текущей сессии; жёсткий выбор модели не задан.
У scout запрет изменений является инструкцией роли, а не отдельной песочницей.
Профиль агента не может предоставить больше прав, чем имеет родитель.

| Навык | Когда нужен |
| --- | --- |
| codebase-scout | Узкий вопрос о коде без правок |
| code-quality-review | Конкретный риск ошибки/производительности |
| security-review | Граница доверия или находка безопасности |
| feature-triage | Идея → задачи и критерии готовности |
| test-selection | Выбор достаточных проверок |
| python-implementation | Реализация Python-поведения |
| openai-integration | Провайдеры, OAuth, streaming, capabilities |
| profile-isolation | Личные данные и смена локального пользователя |
| raspberry-pi-deployment | Диагностика/развёртывание на разрешённом устройстве |
| device-ux-review | Тач, голос и пользовательские состояния |
| ci-policy | Изменение CI и проверок перед слиянием |

Роли: scout исследует; developer реализует; reviewer проверяет корректность;
security проверяет назначенную границу безопасности. Для маленьких задач достаточно
одного агента. Делегирование — при наличии разрешения и независимых частей работы;
оно не запускается автоматически при каждом изменении. Отдельные devops/tester/
feature-manager пока не нужны: соответствующие навыки доступны основному агенту.

## Использование

Открыть Codex в корне GPT-Pi-5. Примеры запросов:
- «Используй $codebase-scout: откуда берётся владелец диалога?»
- «Используй $profile-isolation: проверь смену профиля во время ответа».
- «Используй $feature-triage: подготовь задачу на push-to-talk без записи в GitHub».
- «Поручи scout найти обработку ошибок, reviewer проверить изменения; не меняйте код».

Навыки доступны для обычного автоматического выбора по их описаниям. Проверять
загрузку в конкретной версии клиента отдельно; наличие файла и синтаксическая
валидация не являются доказательством его использования текущей сессией.
У Claude Code/Copilot общие правила подключены существующими файлами-указателями;
Codex-профили не следует считать автоматически совместимыми с другими клиентами.

## Контрольные сценарии поведения

- Правка одного абзаца README: проверить ссылки/перевод, не обращаться к устройству.
- Поиск причины ошибки: scout возвращает путь и доказательства без правок.
- «B получает файл A по ID»: security/profile-isolation проверяет реальную
  авторизацию, а не только фильтр списка, и требует отрицательный сценарий.
- Запрос деплоя без доступа к Pi: подготовить пакет/rollback, не заявлять проверку звука.
- Создание issue без --apply: только локальный preview, без чтения токена/сети.
- Merge с отсутствующим/устаревшим CI: остановиться до изменения GitHub.
