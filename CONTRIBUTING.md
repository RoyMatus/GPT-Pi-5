# Участие

Вопросы, идеи и воспроизводимые баги можно оформлять как issues.
Прямые изменения репозитория доступны только владельцу и явно разрешённым им
инструментам. Публичные PR являются предложениями и требуют решения владельца.

Перед правкой читать AGENTS.md; ограничивать изменение одной задачей, добавлять
значимые проверки и обновлять документацию. Для PR описать проблему, результат,
проверки и ограничения. Не запускать платные API-запросы в CI.
Лицензия пока не выбрана; до её выбора согласовывать существенные внешние вклады.
