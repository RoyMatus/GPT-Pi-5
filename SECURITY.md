# Безопасность

Текущий v0.2 — личный прототип для доверенного пользователя ОС. Реализованы
OAuth/PKCE, проверка ID token и серверные сеансы; HTTP проверяет владельца чата
по действующему сеансу, Host, Origin и CSRF. Сервер слушает только 127.0.0.1.
Не публиковать его в LAN или интернет.

По умолчанию вход сохраняется: облачные токены остаются в backend data-dir,
файлы credentials имеют права 0600, каталог — 0700 на Linux. Чаты и аудио
остаются в RAM; аудио не отправляется в облако. Выход удаляет сохранённый доступ,
отменяет обработку и пытается отозвать токен. Браузерный вход на сайте OpenAI
отдельный: выход из приложения не удаляет cookies OpenAI.

Отдельные защищённые локальные профили, постоянная история и шифрование диска
не реализованы. Нет защиты от root, чтения RAM/диска, захвата браузерного сеанса
или подмены приложения. Текущие границы и проверки описаны в
[архитектуре](docs/ARCHITECTURE.md) и [TESTING.md](TESTING.md).

Будущие границы: локальные люди разделены приложением; владелец/root и физический
доступ — отдельная модель угроз. Общий динамик не обеспечивает акустическую
конфиденциальность. Личные ответы могут требовать наушников/текстового режима.

Не прикладывать к публичным issues токены, пароли, реальные чаты и аудиозаписи.
При обнаружении уязвимости использовать private vulnerability reporting, если
владелец его включил. Иначе сначала запросить приватный канал без деталей эксплуатации.
