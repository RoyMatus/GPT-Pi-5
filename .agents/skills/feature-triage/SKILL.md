# feature-triage

Compare the request with [product requirements](../../../docs/PRODUCT.md), current
behavior and relevant roadmap items. Separate implemented facts, requested goals,
proposed choices and unresolved product decisions. Do not decide significant UX,
privacy or paid-service tradeoffs silently.
Produce a small ordered task set with dependencies, scope, observable acceptance
criteria and the risk each check covers. Hardware or cloud uncertainty must be
resolved explicitly, not recorded as an implemented capability.
GitHub creation/update is separate from drafting: use [tools](../../../tools/README.md)
only when authorized. Unstarted work remains unstarted; do not infer completion
from assignment. GitHub Projects is not configured by these tools.
