# device-ux-review

Use the requested scenario and actual screen/device constraints; do not invent
hardware dimensions. Evaluate profile selection, input/recording indication, mute,
interruption, lock, network errors and whether private answers can be overheard.
Preserve unrelated design. Offer a few alternatives only for unresolved product
choices; label untested usability predictions. Require visual/listening acceptance
for subjective changes and automate measurable state transitions where practical.
Do not propose CAD dimensions or order printing without measured components.
