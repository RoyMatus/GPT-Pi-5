## Истина и границы задачи

- Приоритет — фактическая точность. Разделять факты, решения и гипотезы.
- Не называть заглушки работающими интеграциями. Сообщать, что именно проверено.
- Проверять актуальные OpenAI API, OAuth, модели и ограничения по официальным
  источникам; записывать дату и ссылку. Не переносить ограничения старых лет автоматически.
- Подписка ChatGPT и API-ключ не взаимозаменяемы. Не обещать все функции ChatGPT.
- Один облачный аккаунт не обеспечивает изоляцию локальных людей.
- Не обходить OAuth, ограничения доступа, тарифов или региональную доступность.
- Не читать и не изменять соседние проекты. Сохранять чужие незавершённые правки.

## Безопасность и приватность

- Не сохранять пароли, ключи, OAuth-токены, реальные чаты, аудио и персональные
  данные в Git, логи, issues или промпты. Использовать искусственные тестовые данные.
- Секреты облачного подключения доступны только backend; не помещать в UI/storage браузера.
- Любая операция над диалогом, памятью, поисковым индексом, экспортом или файлом
  должна проверять локального владельца на сервере. ID из клиента не является авторизацией.
- Локальный профиль с PIN/паролем, облачный аккаунт и учётная запись ОС — разные сущности.
- При блокировке/смене профиля отменять запросы, останавливать микрофон и звук,
  закрывать потоковую сессию, очищать UI и контекст. Запоздалые ответы не показывать другому человеку.
- Не включать запись звука постоянно по умолчанию. Нужны явное действие и индикатор.
- Не исполнять произвольные команды от модели. Инструменты разрешать по списку;
  внешние и опасные действия требуют подтверждения пользователя устройства.
- Не обещать защиту от root/владельца диска без отдельной криптографической модели.

## Разработка

Python 3.11+, пакет src/gpt_pi. Пока достаточно стандартной библиотеки.
Не добавлять инфраструктуру и зависимости без нужды. Клиент работает с backend
на loopback. HTTP-демо не предназначено для публикации в LAN/интернет.
Новые интеграции добавлять через отдельные адаптеры и явные capabilities.
Не включать платные API-вызовы в тесты/CI. Не устанавливать ничего на Raspberry Pi
и не менять ОС/автозагрузку только ради локальной правки без задачи на развёртывание.

Проверить `PYTHONPATH=src python -m unittest discover -s tests -v`
(PowerShell: сначала `$env:PYTHONPATH='src'`).
Для авторизации обязательны негативные тесты межпрофильного доступа, устаревших
сессий, подмены ID и перехода пользователя во время ответа.
Обновлять docs/AI_CONTEXT.md и статус roadmap при изменении фактической готовности.
В финале указать изменения, проверки, ограничения и следующий конкретный шаг.
