# GPT-Pi 5

**Русский** | [English](README.en.md)

Настольный помощник на Raspberry Pi 5 с сенсорным экраном и локальным голосовым вводом.
Независимый проект Roy Matus ([RoyMatus](https://github.com/RoyMatus)),
разрабатываемый с помощью ChatGPT; не официальное устройство OpenAI или Raspberry Pi.

**Стадия: личный прототип v0.2. Приёмка микрофона/динамика ещё не завершена.**

## Что работает в прототипе

- Официальные компоненты **Microsoft Fluent 2 / Fluent UI React v9**: светлая/тёмная тема,
  адаптивный экран входа, список разговоров, выбор модели и текстовый чат.
- Кнопка **Continue with ChatGPT** открывает официальный сайт OpenAI. Приложение
  не получает пароль. Реализованы OAuth/PKCE, проверка подписанного ID token,
  обновление токенов и попытка отзыва доступа при выходе.
- Использование доступного плана ChatGPT через документированный Responses API:
  потоковые ответы, остановка, ошибки квот и сетевые ошибки. Отдельный платный API не подключается.
- Вход на личном устройстве сохраняется между перезапусками и не сбрасывается
  через 30 минут. Выход удаляет сохранённый доступ. Чаты остаются только в RAM.
  Данные одного сеанса недоступны другому по HTTP.
- Локальный сервер слушает только `127.0.0.1`; проверяет Host, Origin и CSRF.
  Access-log выключен. Регистрация и токены хранятся только на backend, в каталоге
  пользователя; на Linux файлы токенов имеют права 0600. Шифрование диска не реализовано.
- Установщик пользовательской службы и окна приложения для Pi с Wayland, без sudo.
  Развёрнутое окно совместимо с системной экранной клавиатурой squeekboard.
- Необязательный локальный голос на русском: запись по кнопке до 30 секунд,
  распознавание Vosk, проверка текста перед отправкой и озвучивание Piper.
  Аудио не сохраняется и не отправляется в облако. Кнопка отмены, выход и уход
  со страницы останавливают запись/воспроизведение; ответы до 2500 символов можно прослушать.
- «Проверить звук» доступно до входа и в чате: запись пяти секунд с индикатором
  уровня, прослушивание записи и тест динамика. Проверка остаётся на устройстве,
  не запрашивает камеру и не закрепляет номер USB-порта. На Pi отсутствие аудиовыхода
  определяется отдельно от виртуального Dummy Output.

Вход и вывод ответа покрыты автономными тестами с подменой облака.
2026-11-10 на Pi подтверждены реальный вход владельца, получение моделей и ответ
OpenAI через подключённый план ChatGPT. Это проверка одного аккаунта и текущего
подключения, а не гарантия доступа для других аккаунтов или регионов.
Постоянная история, память, файлы и отдельные защищённые локальные профили
пока не реализованы. Завершение сеанса приложения не выходит из OpenAI в обычном браузере;
установщик kiosk использует отдельный постоянный профиль браузера.

## Запуск из исходников

Нужны Python 3.11+ и Node.js 22+. Сначала собрать интерфейс; Node.js не нужен
на устройстве при установке готового wheel.

```sh
npm ci
npm run build
python -m venv .venv
```

Windows PowerShell:

```powershell
.\.venv\Scripts\python.exe -m pip install .
.\.venv\Scripts\python.exe -m gpt_pi
```

Linux / Raspberry Pi:

```sh
.venv/bin/python -m pip install .
.venv/bin/python -m gpt_pi
```

Открыть http://127.0.0.1:8765 **на той же машине**, где запущен сервер. Для Pi
с другого компьютера использовать SSH-туннель с тем же локальным портом;
не публиковать сервер в LAN. OAuth callback всегда `127.0.0.1`, не `localhost`.
Без сохранённого входа приложение не обращается к OpenAI до нажатия кнопки входа.

Настройки: `GPT_PI_PORT`, `GPT_PI_PROVIDER=chatgpt|offline`, `GPT_PI_DATA_DIR`,
`GPT_PI_REMEMBER_LOGIN=1` (по умолчанию). Значение `0` возвращает вход только в RAM
с выходом через 30 минут бездействия. Данные находятся в пользовательском каталоге приложения.
Сохранение входа не отменяет сроков/отзыва разрешения со стороны OpenAI.
`.env` автоматически не загружается. API-ключи не принимаются.

Для локального голоса на Linux/Pi выполнить `python3 tools/install_voice.py` от
того же пользователя, затем обновить страницу приложения. Установщик скачивает
проверяемые по SHA-256 русские модели и создаёт отдельное окружение в data-dir/voice;
sudo и дополнительный облачный API не нужны. Если задан `GPT_PI_DATA_DIR`, передать
тот же каталог через `--data-dir`. Нажать «Говорить», разрешить микрофон, записать
фразу и нажать «Закончить запись». Проверить текст и отправить стрелкой.
Озвучивание включается после голосового ввода; выключается в настройках.
Это последовательный разговор с локальным голосом, не встроенный Voice Mode ChatGPT.
Синтетическая речь проверена на Pi; слышимость и запись с реального оборудования ещё требуют проверки.

## Проверки и сборка

В активированном venv:

```sh
python -m unittest discover -s tests -v
node --test tests/voice.test.mjs
python -m pip wheel . --no-deps -w dist
```

Сборка wheel требует готового интерфейса. Сгенерированные JS/CSS не редактируются
и не коммитятся; зависимости npm закреплены в package-lock.json.
CI собирает интерфейс, проверяет приложение без облачных ключей и создаёт wheel
на Windows/Linux. Отдельная проверка Chromium на Ubuntu проверяет сохранение входа,
выход и голосовые кнопки с синтетическим облаком и микрофоном; команды — в [TESTING.md](TESTING.md).
Это не заменяет проверку настоящего экрана, аудио и загрузки Pi.

Ассистент встроен во вкладку панели. Переход на другой раздел останавливает голос и активный ответ, сохраняя вход и беседу в RAM.

Компьютер: настраиваемый SSH-источник Linux/Windows, проверка ключа сервера, отдельные публичные ключи телеметрии/SFTP, реальные поддерживаемые показатели и история. Нужен настроенный OpenSSH на выбранном ПК; Pi не выбирается источником автоматически. Политика ключей и ограничений — docs/dashboard/SSH.md.
Рынки: избранное и графики Kraken (криптовалюты), MOEX ISS (задержанные акции/индекс) и официальные курсы ЦБ. Избранное хранится в RAM сеанса. Нефть и металлы явно отмечены как неподключённые.
Календарь: месяцы с понедельника, локальные события (добавление, изменение, удаление) и отсчёт календарных дней. События хранятся только в RAM сеанса и очищаются при выходе/перезапуске. Время события — локальная запись без уведомлений и преобразования в UTC.

Обзор показывает часы, прогноз Open-Meteo и те же показатели ПК/котировки, что подробные вкладки. Город по умолчанию — Москва; его можно выбрать через поиск. Геолокация не запрашивается, выбор города хранится в RAM.
