# GPT-Pi 5

Настольный голосовой помощник на Raspberry Pi 5: сенсорный экран, микрофон,
динамик и корпус, напечатанный на 3D-принтере на заказ.

**Стадия: заготовка для разработки, не готовый голосовой помощник.**
Независимый проект; не является официальным устройством OpenAI или Raspberry Pi.

## Что уже есть

- Запускаемая локальная страница состояния с крупными элементами для тач-экрана.
- Python-сервис на loopback, `/health`, `/api/capabilities` и offline-провайдер.
- Модель отдельных локальных профилей и проверка владения диалогами в памяти.
  Она не заменяет аутентификацию и пока не подключена к HTTP.
- Тесты границ доступа, конфигурации и HTTP; CI для Windows и Linux.
- Проектные требования, архитектура, этапы работ и техническое задание на корпус.
- Инструкции для Codex, Claude Code, GitHub Copilot и других ИИ-агентов.
- Примеры systemd и автозапуска интерфейса; установка на устройство ещё не выполнена.

## Запуск на компьютере

Нужен Python 3.11+. Из корня проекта:

```powershell
# Windows PowerShell
$env:PYTHONPATH = 'src'
python -m gpt_pi
```

```sh
# Linux / Raspberry Pi
PYTHONPATH=src python3 -m gpt_pi
```

Открыть http://127.0.0.1:8765. Остановка: Ctrl+C.
Демо не требует ключей, не обращается к OpenAI, не записывает звук и не хранит чаты.
Для другого порта задать `GPT_PI_PORT`. `.env.example` — справочник;
файл `.env` автоматически НЕ загружается.

Проверки:

```powershell
$env:PYTHONPATH = 'src'
python -m unittest discover -s tests -v
```

```sh
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

## Планируемая работа

После загрузки ОС появляется заблокированный экран выбора локального пользователя.
После личной аутентификации доступны только его чаты, память и созданные файлы.
Владелец настраивает одно активное облачное подключение устройства.
Голосовой разговор и инструменты добавляются поэтапно; доступность определяется
реальными правами выбранного подключения, а не одним названием подписки.

Вход через ChatGPT, применение подписки, API с отдельной оплатой и локальная
изоляция людей — разные задачи. Режим «одна подписка для нескольких людей»
сохранён как пожелание, но его допустимость и доступность не подтверждены.
Нельзя обещать полный набор функций ChatGPT через API. См. [исследование](docs/OPENAI.md).
